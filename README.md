# FaveVerse

A small, responsive character-chat demo: talk with anime-inspired characters, create your own character, and invent worlds.

## Try it

Open [index.html](index.html) in a modern browser. You can also enable GitHub Pages in the repository settings to put the static demo online.

## What works

- Three starter characters, each with a distinct greeting and personality
- Chat interface with demo replies (not a live AI connection)
- Create and switch between your own characters
- Create custom worlds
- Your characters and chat history are saved in your browser with local storage
- Responsive layout for desktop and mobile

## Important

This is a front-end demo. It does not have accounts, cloud sync, or a real AI service yet. Your chats stay in the browser you use. Never put an AI API key in front-end JavaScript; a real AI connection needs a secure server.
